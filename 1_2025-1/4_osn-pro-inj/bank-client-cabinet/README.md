# Практическая работа  
## «Проектирование графического интерфейса пользователя»

**Вариант — Личный кабинет интернет-банка**

---

## 📌 Цель работы
Ознакомление с основными элементами управления (виджетами) и приобретение навыков проектирования графического интерфейса пользователя (GUI) с использованием Python и PySide6.

---

## 🏗 Описание программы
Программа реализует **личный кабинет интернет-банка** с минималистичным интерфейсом. Пользователь может перемещаться между разделами, представленными в виде панели навигации слева. Основная область отображает содержимое выбранного раздела.

### Разделы интерфейса:
- **Главная** — приветственная страница с обзором кабинета
- **Инструкция** — справочная информация для пользователя
- **Регистрация** — регистрация нового пользователя
- **Платежи и переводы** — управление счетами и платежами
- **Счета** — просмотр текущих счетов
- **Персональные настройки** — редактирование информации пользователя

---

## 🎨 Особенности дизайна
- Минималистичный интерфейс с аккуратными отступами
- Левая навигационная панель с иконками и hover/pressed эффектами
- Основная рабочая область с закругленными углами и достаточными отступами
- Используются стандартизированные шрифты и приятная цветовая гамма
- Легко расширяемый: можно добавлять формы, таблицы и интерактивные элементы

---

## 🛠 Используемые технологии
- Python 3.13+
- PySide6
- Qt Designer (по желанию для макетов)
- Иконки PNG для навигации
