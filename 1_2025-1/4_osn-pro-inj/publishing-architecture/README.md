# Практическая работа  
## «Построение архитектуры программного средства»

**Вариант №12 — Архитектура издательства**

---

## 📌 Цель работы
Изучение базовых принципов построения архитектуры программных средств, 
выбор архитектурного стиля и шаблонов проектирования, а также освоение 
системы контроля версий Git и сервиса GitHub.

---

## 🏗 Описание архитектуры

Программное средство «Издательство» реализовано с использованием 
**многослойной архитектуры (3-tier architecture)**:

### 1. Пользовательский интерфейс (UI)
- Веб-интерфейс
- Автор
- Редактор
- Администратор

### 2. Бизнес-логика
- Управление рукописями
- Редактирование
- Планирование публикаций
- Формирование заказов на печать

### 3. Слой доступа к данным
- База данных издательства
- Хранение авторов, книг, заказов и публикаций

---

## 🧩 Архитектурный стиль
- Многослойная архитектура
- Компонентный подход
- Принцип единственной ответственности
- Слабая связанность компонентов

---

## 📊 Диаграмма архитектуры
Диаграмма архитектуры издательства формируется автоматически 
с помощью Python-скрипта `main.py` с использованием **matplotlib** и сохраняется в формате PNG (`publishing_architecture.png`).
